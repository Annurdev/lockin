# Lockin — Reader App Designs

Mobile UI concepts for a fiction marketplace where readers discover, purchase, read and share complete books and ongoing series. Authors use a separate website.

## Design files

- [Approved screens](designs/01-Approved-Screens): 35 numbered standalone PNGs.
- [Earlier concepts](designs/02-Earlier-Concepts): 3 initial concepts and alternatives.
- [File manifest](designs/manifest.json): filenames, sizes and SHA-256 hashes.

The approved visual direction uses warm cream backgrounds, espresso serif typography, sage and honey accents, and hand-drawn literary illustrations.

These are static UI designs, not an implemented application or editable Figma project. Names, prices, transactions and support requests are illustrative sample content. Payment integrations and platform requirements need review during implementation.

## Download

Use **Code → Download ZIP** on GitHub to download all files, or open an individual PNG and download it.
